# 驭能管家

一款自用的、使用Deepseek Harness开发的记录纯电、燃油、插电混动汽车充电/加油/收入/支出的 Android 应用，支持油耗、电耗、综合能耗、费用与电池健康统计，并按比亚迪第五代 DM-i 的 46.06% 发动机热效率做能耗折算。

当前版本 **v1.2.0**：充电金额与剩余油量允许填 0；保存充电/加油记录后直接显示本次行程报告，记录列表每条记录底部也有本段摘要，点击即可查看；备份与恢复合并为一个入口。

## 功能

- **多车型**：纯电、燃油、插电混动、增程；每辆车独立记录与统计，可设置默认车辆并随时切换；支持删除车辆（会同时删除该车记录，且至少保留一辆车）。
- **记一笔**：底部悬浮按钮展开“收入 / 记能耗 / 支出”快捷菜单。
  - 充电：充电金额 = 充电电量 × 折合电价。电价由你手填时以电价为准重算金额或电量；电价留空（或由金额、电量算出）时，改动金额或电量只会刷新电价，不会覆盖你正在填的金额或电量。另有开始/结束电量、剩余油量（必填，可填 0）、站点、备注、照片。充电金额允许填 0（例如免费充电），但电量仍需填写。
  - 加油：机显单价 × 加油量 = 机显金额，机显金额 − 优惠金额 = 实付金额，实付金额 ÷ 加油量 = 实付单价；改动「机显单价 / 加油量 / 机显金额」任意一项，另外两项会自动重算；改动「实付单价 / 优惠金额 / 实付金额」任意一项，另外两项也会自动重算。加油前后油量、加油时剩余电量（必填）；油品型号支持乙醇汽油（E92#/E93#/E95# 等）、汽油（90#/92#/95#/98# 等）、柴油（0#/-10#/-20# 等）和其他（天然气 CNG/LNG、液化石油气、甲醇、乙醇、氢能、生物柴油等）。
  - 收入/支出：类型、金额、备注、照片；收支不计入能耗统计。
- **统计时间范围**：能耗页「统计」卡与「能耗变化趋势」共用同一个时间窗口，点击「近一年 ▾」在「近一年 / 年度 / 月度 / 自定义」间切换，趋势图随之联动；「电池容量衰减趋势」卡可单独选择。统计页不提供时间选择，总支出、费用构成、分类排行都是“从记录开始到现在”的全量口径，彼此联动。费用页只在绿色「总支出」卡右上角提供时间选择（默认近一年），费用构成、支出月度统计、支出明细、收入全部跟随它联动。自定义区间最多 3 年。
- **记录流水**：按年月分组，支持全部/充电/加油/收支筛选，点击记录可编辑或删除；每条充电/加油记录底部带一条本段摘要（元/公里 · 升/百公里 · 度/百公里），点击摘要即可查看该次行程报告。
- **能耗首页**：最近综合能耗、平均油耗/电耗、累计里程、能耗花费、平均能费、能耗趋势、电池容量衰减趋势。
- **费用统计**：总支出拆解、费用构成环形图、月度柱状图、分类排行、收支明细。
- **行程报告**：每次新增充电/加油记录保存后，会自动展示这一段的行程报告——行驶天数、本段距离与日均、油/电消耗与花费、每公里能费，并与上一条记录的总里程对比；某条记录缺少上一条带里程的记录时会提示无法计算。分享按钮可把报告文本发到微信等应用。
- **位置**：首页左上角调用系统定位，逆地理编码显示当前城市；点击可手动刷新，未授权时引导开启定位。
- **数据管理**：「备份与恢复」在同一个弹窗里：备份通过系统保存对话框选择手机上的任意位置（下载、文档、网盘等），文件名带时间戳；恢复从备份的 .db 文件还原全部车辆与记录，会覆盖当前数据（先确认再选择文件）；导出 CSV 后会提示「分享」，可直接把文件发送到微信、QQ、邮件等应用。CSV 导入从文件追加记录、不删除已有数据；另有清空全部数据（删除所有车辆与记录，操作前需两次确认）。备份与导出前都会弹确认框，避免误触。点击「导入 CSV」时，弹窗里同时提供「选择文件」和「导出模板」：导出的模板包含表头和 3 行示例（充电 / 加油 / 支出），可直接分享到微信、文件传输助手等应用。CSV 共 20 列，第 16–17 列为「充电时剩余油量」「加油时剩余电量」（插电混动与增程车会写入对应数值，其他车型留空），最后三列为「实付金额(元)」「优惠金额(元)」「实付单价(元/升)」。
- **外观**：8 套全局配色（翡翠绿 / 天空蓝 / 紫罗兰 / 日落橙 / 玫瑰红 / 石墨灰 / 青碧 / 珊瑚），在「我的 → 全局配色」切换后整个应用即时生效，并记住选择。
- **车型适配**：纯电隐藏加油入口与剩余油量，燃油车隐藏充电入口与剩余电量；插电混动与增程车两种记录都保留；统计卡按车型显示电耗/油耗/DM-i 或增程折算。

## 统计口径

- 平均油耗 = 总燃油 ÷ 总里程 × 100（L/100km）
- 平均电耗 = 总电量 ÷ 总里程 × 100（kWh/100km）
- 插混综合能耗 = 平均油耗 + 平均电耗 × 0.31（L/100km）
- 平均能费 = 能耗总花费 ÷ 总里程（元/km）
- 第五代 DM-i：热效率 46.06%，电驱效率 92%，汽油低热值按 8.9 kWh/L 折算：
  - 每升油发电 ≈ 8.9 × 46.06% × 92% ≈ 3.77 kWh
  - 等效油耗 = 平均油耗 + 平均电耗 ÷ (8.9 × 46.06% × 92%)
- 电池容量由充电记录估算：电量 ÷（结束 SOC − 开始 SOC）× 100，取最近 8 次有效充电均值；健康度为估算容量 ÷ 标称容量。
- 纯电 / 燃油 / 混动里程：用相邻两条能耗记录之间的状态变化判定。前一条的“补能后状态”（充电结束电量与剩余油量、加油后油量与加油时剩余电量）与本条的“补能前状态”比较，本轮只降电（SOC 下降 ≥ 2%）记为纯电里程，只降油（油量下降 ≥ 2%）记为纯油里程，两者都降记为混动里程；纯电电耗 = 总电量 ÷ 纯电里程 × 100。这套拆分对插电混动与增程车生效，纯电与燃油车直接按车型归入对应里程。
- 时间窗口：区间为左闭右开 `[起始日 00:00, 结束日次日 00:00)`；里程以窗口起点之前最后一条能耗记录为基线，所以“2025 年”的里程等于 2024 年最后一条里程到 2025 年最后一条里程之间的差值。区间天数按起始日到今天（或区间结束日，取较早者）计算，用于“成本/天”。

> 说明：v1.1.2 起统计范围改为“页面内联动”：能耗页统计卡与趋势图共用一个窗口、电池卡独立；统计页固定全量；费用页所有卡片跟随绿色总支出卡的时间窗口。不传时间窗口的统计接口仍保持全量累计口径。

## 首次启动

首次启动不生成演示记录：只创建一辆“我的爱车”（动力类型未设置，可在“我的车辆”中补充），首页、统计、图表均为空，等待用户添加第一条充电或加油记录。

## 构建

环境要求：

- JDK 21
- Android SDK Platform 34、Build-Tools 34.0.0
- PowerShell 7（Windows）

项目不依赖 Gradle/AndroidX，使用 Android Framework Java + 自定义 View + SQLite 手工构建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\build.ps1
```

脚本依次执行 aapt2 资源编译、javac、d8、zipalign、apksigner，运行 JVM 统计测试，最后打包源码 zip。产物：

```text
dist/驭能管家-1.2.0.apk
dist/驭能管家-1.2.0-source.zip
```

安装：

```powershell
adb install -r dist/驭能管家-1.2.0.apk
```

```text
app/src/main/

  java/com/yuneng/guanjia/

    ui/screens/                # 首页、费用、统计、我的、流水、行程、车辆、表单
    ui/widgets/                # AppBar / BottomBar / FormRow / Segmented / PickerDialog / RangePicker / IconView
    ui/charts/                 # LineChartView / BarChartView / DonutChartView
    util/                      # Formats

tools/
  build.ps1                    # 一键构建
  add_dex.py                   # 将 classes.dex 写入 APK
  make_source_zip.py           # 打包源码 zip
  TestStats.java               # 统计引擎 JVM 测试（含时间窗口用例）

  驭能管家-1.2.0.apk
  驭能管家-1.2.0-source.zip
```

应用包名 `com.yuneng.guanjia`；数据库 `yunengguanjia.db`；备份/导出文件名前缀“驭能管家_”。

## 已知限制

- 备份由系统文件选择器决定落点（下载、文档、网盘等），暂未接入自动云同步；CSV 导出到应用外部目录后可一键分享。
- 使用 Android Debug 证书签名，适合本地安装体验，不用于应用商店发布。
- 未做 Room/Compose 迁移，全部 UI 由 Java 代码构建。
- 能耗页「统计」卡与「能耗变化趋势」共用时间窗口，电池容量趋势卡单独选择；费用页所有卡片跟随「总支出」卡；统计页固定为全量口径。
- 年度 / 月度选择器只列出最近 10 年与最近 24 个月，更早的数据请用“自定义”区间查看。
- 定位需要系统位置权限；拒绝后可在首页点击左上角位置重新授权。
